# SmartGain

動画ごとに違う音の大きさを自動でそろえる Chrome 拡張機能です。YouTube・Twitch・指定したサイトで動きます。

- **音の大きさを自動でそろえる**（Auto-Gain）：再生中の音声のラウドネスを測り、目標の大きさに合わせて増幅・減衰します。手動の音量は「マスター音量」として残ります
- **動画内の音量差を縮める**：小声と叫び声、会話と BGM の差をダイナミクス圧縮で縮めます
- **右クリック＋ホイールで音量を変える**：変えた値と、Auto-Gain の補正量をプレイヤー上に表示します
- **既定の音量・サイトごとの有効化**

## 入手・導入

Chrome ウェブストアには出していません。紹介ページから zip をダウンロードし、デベロッパー モードの「パッケージ化されていない拡張機能を読み込む」で導入します。手順・更新方法・更新履歴は紹介ページにあります。

**https://vel.works/chrome_ext/smartgain/**

このリポジトリをそのまま読み込んでも動きます（リポジトリ直下が拡張のフォルダです）。

## 権限と通信

- 権限は設定の保存（`storage`）だけです。動画のページで音声を処理するため、content script はすべてのサイトで読み込まれ、設定で有効にしたサイトでだけ動きます
- 拡張機能からの通信はありません。設定は Chrome の同期ストレージに、動作の記録（デバッグログ）はこの Chrome の中に保存します

## 開発

ビルドはありません（Manifest V3・素の JavaScript）。

| パス | 内容 |
|---|---|
| `content.js` | content script。設定・ホイール操作・音量の表示（OSD）・デバッグログの保存 |
| `inject.js` | ページ側で動くスクリプト。Web Audio による Auto-Gain、プレイヤーの音量制御 |
| `options.*` | 設定画面 |
| `test/` | 実際の Twitch / YouTube で挙動を記録する検証スクリプト（Python + Playwright）。[test/README.md](test/README.md) |
| `scripts/release.py` | 配布用 zip を作る |

manifest の `key`（公開鍵）で拡張 ID を固定しています。新しい版を別のフォルダに展開しても、設定が引き継がれます。
